Phiên làm việc vừa bị gián đoạn. Hãy khôi phục context và tiếp tục:

1. Đọc entry mới nhất trong `docs/CHANGELOG.md` → biết task đang làm gì
2. Quét `src/` tìm file chứa `// TODO:` hoặc method body trống → biết còn dở chỗ nào
3. Tóm tắt ngắn: "Đang làm [X], đã xong [Y], còn thiếu [Z]"
4. Hỏi tôi xác nhận rồi tiếp tục

Ưu tiên hoàn thành từng file một. Xong task thì nhắc gọi /task-done.
