Đọc các file sau theo thứ tự để nắm lại toàn bộ context:
1. CLAUDE.md
2. docs/conventions.md
3. docs/api-mapping.md (xem các endpoint nào ✅ đã xong, ⬜ chưa làm)
4. docs/analysis-report.md (nếu đã tồn tại)

Sau khi đọc xong, báo cáo lại cho tôi:
- Đang làm dở module nào (nếu có file .cs nào được tạo gần đây)
- Danh sách module đã hoàn thành
- Module tiếp theo cần làm
- Có file nào tạo dở (thiếu Validator, thiếu DI registration, v.v.) không?

Chưa cần làm gì thêm, chỉ báo cáo trạng thái rồi chờ tôi xác nhận.
